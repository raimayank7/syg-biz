Rent book

One row for each tenant and month: rent, amount received, what is due, with a reminder message.

What it is for

A landlord with three or ten tenants keeps losing track of who paid which month. The rent book keeps one row for each tenant and month, shows what is still due and copies last month's tenants into a new month in one tap.. It is built for rent from flats, rooms or shops let out.

How to use it

  1. Add each tenant for the current month with the rent.
  2. When money arrives, edit the row and write the amount received and the date.
  3. At the start of a new month tap "Copy last month's tenants into this month".
  4. Rows with rent still due appear under "Needs attention", with a reminder message button.

Common questions

Where are the records kept?

In your own browser on this device. Download a backup file now and then.

Can I move the data to a spreadsheet?

Yes. Use "Download as a spreadsheet file (.csv)" at the bottom of the register.
