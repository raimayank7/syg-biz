Progress note phrases for tutors

A good note is short and specific. Pick one line from each group below, fill the brackets and send. These are our own wording.

Something going well

[Name] has become much faster at [topic] this month and now finishes the practice sheet without help.

[Name] asks good questions in class, especially about [topic]. This shows real thinking.

[Name]'s handwriting and neatness in [subject] have improved clearly.

Something to work on

[Name] still makes mistakes in [topic]. We will do ten minutes of practice on it at the start of each class.

[Name] loses marks by reading the question too quickly. Please remind [Name] to read it twice.

Homework has been missed [number] times this month. Fifteen minutes each evening would help a lot.

Attendance and effort

[Name] attended [number] of [number] classes this month. Regular attendance is helping.

[Name] is trying hard. Marks may take another month to show it, but the effort is clear.

Tests

In the test on [date], [Name] scored [marks]. The strong part was [topic]; the topic to revise is [topic].

Next step

Next month we will focus on [topic]. You can help by [asking [Name] to explain one thing taught each day].

Add a line of thanks at the end of each note. If you run a batch, keep the notes in the same order every month so parents know what to expect. The parent communication guide has a full routine.

Common questions

How long should a progress note be?

Three to five lines is enough. If you need more, call the parent.

Should I put marks in every note?

Only when there has been a test. Between tests, describe the work, the effort and one thing to improve.
