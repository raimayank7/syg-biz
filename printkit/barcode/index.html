Barcode generator

Type a code, choose a type and download a barcode as an image. For a full sheet of labels use the label maker.

Test-scan before you use it. This barcode is drawn by our own code, which we could not test with a scanner. Print it and scan it with the scanner or phone you will use.

Choosing a type

Use Code 128 for your own codes with letters. Use EAN-13 only when you have a real 13-digit number to print, such as one given to you, because numbers for goods sold to the public come from a numbering system. For a full explanation read barcode basics.

What the check digit is

Type twelve digits and the generator adds the thirteenth, the check digit. If you type thirteen and the last is wrong, it tells you what it should be.

Common questions

Is the barcode saved anywhere?

No. It is drawn in your browser. The SVG file you download is yours.

Can I scale the image?

Yes, it is a vector file. Keep a quiet blank margin around it and do not stretch it taller or wider than it was drawn.
