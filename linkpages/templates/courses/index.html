Course page examples

Three kinds of class and what each page needs to say.

The names, prices and dates are made up. The button opens the builder with the example filled in, and you replace the words with yours.

Course page for a tuition batch

A tuition page answers the four questions parents ask: what is taught, how big the batch is, when it meets and how much it costs.

Tip. Add the first month free for a demo class or a refund rule in the description, and say how many seats are left.

Open this example in the builder

Page for a one-day workshop

A workshop is a one-time event with a set date and a limited number of seats, so the page must make the date and the price impossible to miss.

Tip. Say what the attendee can do at the end that they could not do before, in one line.

Open this example in the builder

Page for an online class or webinar

An online class has no place to find, so the page needs a clear promise and a clear way to join after payment: write in the description how the link will be sent.

Tip. After payment, send the joining link on WhatsApp the day before. Keep a list of who paid in your lead tracker.
