Writing product descriptions that sell

A good description answers the questions a customer would ask in the shop. Keep it to one line in a catalogue, and put the details in a message.

A simple formula

What it is + the size or quantity + one fact that matters. For example: "Cotton kurti, sizes S to XXL, machine washable". The fact that matters is the one that stops a question: size, material, colour, how long it lasts, what is included.

Examples

Soy wax candle, 150 g, burns for about 25 hours. Vanilla scent.

Steel water bottle, 750 ml, keeps drinks cold for hours. Leak-proof lid.

Cotton kurti in blue print, sizes S to XXL. Colours may look slightly different on screen.

Numbers beat adjectives

"Large" tells nothing; "30 cm wide" tells everything. "Long lasting" is a claim; "burns for about 25 hours" is a fact the customer can test. Only give a number you have checked yourself.

Say what is not included

"Without plant", "bulb not included", "frame only". It stops disappointment and returns.

Claims to avoid

  • "Best", "number one" and "100 percent pure" unless you can prove them.
  • Health or medical claims, especially for food, oils or herbal items.
  • A brand name for something that is not from that brand.
  • Anything about your competitors.

Keep it short

The catalogue maker allows 140 characters for a description, enough for one clear line. Longer details such as washing instructions can go in a message that you send after the customer asks.

Hindi and Punjabi

If your customers read Hindi or Punjabi, write the description in the language they use at home. Write the item name in the same language as the description so that the list reads smoothly.

Common questions

Should I write in English or Hindi?

Use the language your customers speak. Many shops write the name in English and the description in Hindi or Punjabi.

How do I list sizes?

Put them in the description as a range ("S to XXL") and ask for the size in the order message.
