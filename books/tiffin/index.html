Tiffin and subscription book

Customers, plans, start dates, the day each plan ends and what is unpaid.

What it is for

A plan that ends quietly is a customer you lose without knowing. The book works out the last day of every plan, shows plans ending soon and unpaid balances, and has a renewal message ready.. It is built for tiffin, milk, newspaper and other plans that run for a number of days.

How to use it

  1. Add the customer, the plan, the start date and the number of days.
  2. Write the price and what has been received.
  3. The "Ends on" column shows the last day; plans ending in 3 days show under "Needs attention".
  4. Tap Plan ending to ask the customer to renew on WhatsApp.

Where are the records kept?

Can I move the data to a spreadsheet?

Yes. Use "Download as a spreadsheet file (.csv)" at the bottom of the register.
